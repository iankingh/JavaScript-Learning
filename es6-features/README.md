# ES6+ Features

ES6（ECMAScript 2015）及後續版本的語法特性範例。

## 涵蓋主題

- `let` / `const` 與 block scope
- 箭頭函式（Arrow Functions）
- 解構賦值（Destructuring）
- 展開運算子（Spread / Rest）
- 模板字串（Template Literals）
- 類別（Class）語法
- 可選鏈（Optional Chaining `?.`）與空值合併（`??`）
- Symbols 與 Iterators
- Generators

## 檔案清單

| 檔案 | 說明 |
|---|---|
| [demo.js](demo.js) | 入門範例，涵蓋上述所有主題 |

## 執行方式

```bash
node demo.js
```

> 模組系統（ESM `import` / `export`）需搭配 `package.json` 的 `"type": "module"`，之後會另以獨立範例補充。
