# DOM Manipulation

DOM 操作與事件處理範例。

## 涵蓋主題

- 選取元素（`querySelector`、`getElementById` 等）
- 新增 / 修改 / 刪除 DOM 節點
- 事件監聽（`addEventListener`）與事件委派
- 事件冒泡（Bubbling）與捕獲（Capturing）
- `classList` 操作
- 表單驗證

## 檔案清單

| 檔案 | 說明 |
|---|---|
| [index.html](index.html) | 互動式入門範例，涵蓋上述主題 |

## 執行方式

直接用瀏覽器開啟 `index.html` 即可互動操作。
